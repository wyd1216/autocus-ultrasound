# Code Availability Draft

Use this text as a starting point when updating the manuscript after the GitHub repository is public.

```tex
The source code, model definitions, preprocessing utilities, configuration templates, and example inputs for the AutoCUS research framework are available at \url{https://github.com/wyd1216/autocus-ultrasound}.
The repository provides runnable demonstration workflows using example inputs and supports re-training with public or approved local data.
The clinical datasets and linked metadata used in this study are not publicly available because of institutional ethics, privacy, and data-governance restrictions.
Model checkpoints used for the reported experiments are not released with the public code repository because they were trained on restricted clinical data and remain subject to institutional and intellectual-property review.
```
